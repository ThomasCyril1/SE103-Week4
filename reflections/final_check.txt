What a pull request asks teammates to do:
A pull request asks teammates to review proposed changes before they are merged into the main branch. It gives reviewers an opportunity to check the changes, provide feedback, and identify possible problems.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately from the main branch, while pull requests provide a structured way to review those changes. Together, they help teams organize development and reduce the risk of adding unreviewed changes to the main branch.
